## Browser and DevTools Practice

I opened the webpage in a browser and used Chrome DevTools to inspect its HTML structure through the Elements tab. In the Network tab, I reloaded the page and observed the document request.

## What Happens When I Enter a URL?

When I enter a URL in a browser, the browser identifies the website's address and finds the server using DNS when necessary. It establishes a connection with the server, sends an HTTP or HTTPS request, and receives a response. The browser then processes the returned HTML and loads any required resources to display the webpage.
